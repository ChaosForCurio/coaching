## What is DCA?

DCA is a 6-month to 1-year diploma program that teaches comprehensive computer skills. It is recognised by government and private sector employers across India and is especially valuable for jobs that require computer proficiency certificates.

## DCA Syllabus — Module-wise

### Module 1: Computer Fundamentals
- Introduction to computers
- Hardware components (CPU, RAM, storage, peripherals)
- Operating systems (Windows 10/11)
- File management, shortcuts

### Module 2: MS Office Suite
- **MS Word:** Document creation, tables, mail merge, formatting
- **MS Excel:** Formulas, functions (VLOOKUP, IF, SUMIF), charts, pivot tables
- **MS PowerPoint:** Slide design, animations, presentations
- **MS Access:** Basic database concepts

### Module 3: Internet & Communication
- Web browsing, Google search
- Email (Gmail, Outlook)
- Online safety and cybersecurity basics
- Video conferencing (Zoom, Google Meet)

### Module 4: Accounting Software
- Tally Prime basics
- GST voucher entry
- Balance sheet overview

### Module 5: Programming Basics (Optional Advanced Module)
- Introduction to programming concepts
- HTML basics for web pages
- Python fundamentals

### Module 6: Project Work & Practical
- Mini-project submission
- Practical exam
- Certificate issuance
